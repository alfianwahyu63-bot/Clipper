VIRALCUT STUDIO V2.2 – PERBAIKAN ERROR "Cannot find module blob:..."

Masalah di V2.1: pekerja WebAssembly bawaan @ffmpeg/ffmpeg versi UMD
memperlakukan import URL blob sebagai nama modul webpack.
V2.2 menggunakan worker ESM lokal yang memanggil import() native browser.

UPLOAD KE GITHUB
1. Ekstrak ZIP ini di HP.
2. Di repository GitHub Clipper, upload seluruh isi hasil ekstrak ke ROOT.
3. WAJIB upload file BARU ffmpeg-worker-v22.js bersama index.html dan sw.js.
4. Timpa file lama, commit changes.
5. Jika Cloudflare Pages terhubung ke repo ini, tunggu deploy sukses.
   Alternatif: GitHub Pages juga bisa memuat berkas tersebut.
6. Tutup PWA/Chrome lalu buka situs lagi. Bila perlu refresh atau hapus
   cache situs agar service worker versi baru menggantikan yang lama.

TEST BERURUTAN
- Upload MP4 kecil 5–15 MB terlebih dahulu (bukan 75 MB).
- 1 klip, 15 detik, 9:16.
- Klik Generate Viral Clips.
- Koneksi internet diperlukan untuk mengunduh FFmpeg Core ~30MB.
- Setelah uji berhasil, tingkatkan ukuran video perlahan.

CATATAN: Kode diperiksa sintaksnya, tetapi belum diuji ekspor video
langsung di Chrome Android/Cloudflare Pages pada perangkat pengguna.
Jika error baru muncul, kirim screenshot baru.
Untuk 75 MB RAM HP dapat menjadi hambatan meski kesalahan modul hilang.
Mode YouTube dari link, subtitle AI, dan analisis isi percakapan
masih memerlukan layanan backend terpisah.
